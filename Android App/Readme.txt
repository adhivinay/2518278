=============================================
SmartSelect Android App - README
=============================================

✅ Authentication:
   Firebase Auth enabled.
   Demo user credentials:
   - Email: demo@smartselect.com
   - Password: 123456

✅ Core Features:
   - Login screen (Firebase Auth)
   - Multi-Agent AI: Users can select a single bot or use "All" mode.
   - Bots: Gemini, ChatGPT, Copilot, Grok (via alternative APIs)
   - Responses styled for each bot for clarity.

✅ How to run:
   1. Open the "SmartSelectAndroid" folder in Android Studio.
   2. Place your "google-services.json" file in the `/app` directory.
   3. Sync Gradle.
   4. Connect to Firebase if needed.
   5. Run the app on an emulator or real device.
   6. Login with the demo credentials.
   7. Enter your query and select a bot (or All).

✅ API Hosting:
   All AI bots route through a Vercel deployment connected to GitHub.

✅ Demo Video:
   Please watch SmartSelect_Demo.mp4 in this zip for full walk-through.
