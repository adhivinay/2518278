# SmartSelect AI Hub Prototype — Android App

This folder contains the **Android Studio project** and/or the **built `.apk` file** for the SmartSelect AI Hub prototype.

---

## 📲 How to Install on a Real Android Phone

1. Copy `SmartSelect.apk` to your Android device.
2. On your phone, open your file manager and locate the `.apk`.
3. Tap to install:
   - You may need to allow **Install from Unknown Sources** in your settings.
   - Follow the prompts to complete installation.
4. Open the app and explore its features!

✅ Done — you’re now running the prototype on your phone.

---

## 💻 How to Run on a PC

### ✅ Option 1: Using Android Studio Emulator

1. Install **Android Studio** (if not installed).
   👉 [Download Android Studio](https://developer.android.com/studio)

2. Open Android Studio.
3. Click **Tools > Device Manager** (or **AVD Manager**).
4. Create a new **Virtual Device** (like Pixel 5) if you don’t have one.
5. Start the emulator.

6. **Install the APK:**
   - Drag & drop the `SmartSelect.apk` onto the emulator window.
   - The emulator will install it automatically.

7. Launch the app on the emulator.

---

### ✅ Option 2: Using a Lightweight Android Emulator

If you don’t want to install Android Studio, you can use **Bluestacks** or **NoxPlayer**:

- [Bluestacks](https://www.bluestacks.com)  
- [NoxPlayer](https://www.bignox.com)

**Steps:**
1. Install Bluestacks or NoxPlayer.
2. Open the emulator.
3. Drag your `SmartSelect.apk` into the emulator window, or use its built-in file manager to locate and install it.
4. Click the app icon to run the prototype.
